# Hydration Reminder App

A desktop hydration reminder application built using Python Tkinter.

## Features

* 10-minute hydration timer
* Visual water glass indicator
* Alarm notification when timer finishes
* Water intake tracking
* Modern dark-themed UI

## Technologies Used

* Python
* Tkinter
* Pillow
* Pygame

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python hydrate.py
```
